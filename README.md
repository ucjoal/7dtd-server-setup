# 七日杀服务器搭建：4核8G 起步的配置选型、SteamCMD 开服与端口调试全流程

开七日杀服务器的人，卡住的地方往往不是命令行，而是买机器那一步。买小了，血月一到就崩；买大了，四个人玩却付着二十人的钱。这篇文章按"先算需求、再选配置、最后开服"的顺序走一遍，中间会用到雨云的游戏云机型做具体例子。

## 先决定：自建 PC 还是租服务器

用家里的电脑跑服务端完全可行，SteamCMD 三条命令就能拉下来。但你得接受几件事：机器 24 小时不能关，路由器上要开端口，家用宽带的上传带宽通常撑不住几个人，而且服务端和你玩游戏的客户端在同一台机器上时，内存需求是加倍的。

最后这条不是猜测。Steam 商店的说明里写得很直白：专用服务器和客户端跑在同一台电脑上，内存要求翻倍。参考数值是客户端最低 8GB、推荐 12GB，翻倍之后就是 24GB 起步。

如果只是想和朋友在同一个网络里试一下，本机开服没问题。但要让外面的人随时能进、还要保证存档不丢，租一台服务器是更省心的选择。

## 七日杀服务器真正吃什么资源

### CPU：单核频率比核心数重要

七日杀的主世界模拟大部分跑在单线程上，主机商 LOW.MS 的技术指南里也提到这一点——快核心比一堆慢核心更能提升区块生成和世界模拟的速度。所以选游戏服务器时，看到"32 核 2.0GHz"和"6 核 5.0GHz"，后者对七日杀往往更合适。

雨云的游戏云产品线主打的就是高主频 CPU，机型涵盖 Intel i9 14900K/14900KF/13900KF、AMD Ryzen 9950X/7950X/5900X、EPYC 7A23、Gold 6146、E5 2666v3 等。以 i9 14900KF 机型为例，官方描述是屏蔽小核、只保留大核，避免虚拟机被调度到低性能小核上。这类设计对单线程敏感的游戏服务端是有实际意义的。

### 内存：不够不是变卡，是直接崩

七日杀的内存不足表现得很暴力。它不会像某些服务端那样慢慢变慢，而是直接崩溃退出，而崩溃最容易发生在血月期间——这时候正在写存档，一次意外退出就可能把存档搞坏。

社区总结的经验值大致是这样：

- 每多一个在线玩家，服务端额外占用 100–200MB 内存，装 mod 会更高
- 默认地图大小是 8K（8192 格宽），可以生成 4K、6K、10K 甚至 16K；玩家分散得越开，同时加载的区块越多
- 大型 overhaul mod（比如 Darkness Falls、Undead Legacy）会额外吃掉 4–8GB 内存，Darkness Falls 官方就明确建议专用服务器至少 12GB

### 带宽：上传是瓶颈

七日杀对带宽的要求不算高，但方向要对——它是上传带宽决定别人能不能进来。主机商 loafhosts 给出的参考是：4 人 8GB 内存、8 人 12GB、16 人 16GB。京东云的官方文档对七日杀轻量云主机的建议是 4 核 8G、5M 带宽、80G 硬盘起步。

按人数整理一下大致对应关系：

| 在线人数 | 建议 CPU | 建议内存 | 建议硬盘 | 说明 |
| --- | --- | --- | --- | --- |
| 2–4 人 | 4 核高主频 | 8GB | 50GB SSD | 原版、8K 地图够用 |
| 4–8 人 | 4 核高主频 | 8–12GB | 80GB SSD | 原版舒适区，可带轻量 mod |
| 8–16 人 | 6 核以上 | 16GB | 100GB+ SSD | 建议上高防，血月峰值明显 |
| 16 人以上或大型整合包 | 8 核以上 | 24–32GB | 150GB+ SSD | 内存留足余量，别卡着线买 |

硬盘部分要单独提一句：服务端文件加上存档，再叠几个 mod，50GB 会很快见底。七日杀服务端本体的安装包就不小。

## 配置选型：为什么开服更适合游戏云

普通云服务器和游戏服务器最大的差别在两处：CPU 主频，和防御。

高主频前面说过了。防御这块，公开服务器基本躲不开被扫端口、被压测。雨云游戏云机型普遍带高防，不同地区防御规格不同——镇江机型标称 200G 高防，宁波、温州等地是 100G 级别，宿迁机型是 150G 级别。具体数值以你选的机型页面为准。

另外一个实际问题是系统选择。七日杀服务端在 Windows 上部署最省事（直接跑 `7DaysToDieServer.exe`），在 Linux 上需要 `lib32gcc-s1` 之类的 32 位依赖，还要用 screen 或 systemd 托管进程。雨云游戏云 VPS 同时支持 Windows 和 Linux，选哪个都不卡。

需要注意：雨云的面板服主要在 MC 生态里做得比较熟（一键开服、预装整合包这类），七日杀服务端要走 SteamCMD 手动部署，直接选游戏云 VPS 自己装系统更稳，不用绕面板。

## 开服：SteamCMD 拉服务端的完整命令

七日杀专用服务器的 Steam AppID 是 **294420**，匿名登录即可下载，不需要你的个人 Steam 账号。

Linux（以 Ubuntu 22.04 / 24.04 为例）：

bash
sudo apt update && sudo apt install -y screen wget lib32gcc-s1
mkdir -p ~/7dtd && cd ~/7dtd
wget https://steamcdn-a.akamaihd.net/client/installer/steamcmd_linux.tar.gz
tar -xvf steamcmd_linux.tar.gz
./steamcmd.sh


进入 SteamCMD 提示符后：


force_install_dir ~/7dtd/server
login anonymous
app_update 294420 validate
quit


注意 `force_install_dir` 必须在 `login` 之前执行，否则文件会装到默认的 Steam 目录里去，而且目录要事先存在。

Windows 上流程一样，只是换成下载 `steamcmd.zip`、解压后运行 `steamcmd.exe`，命令序列完全相同。装完在服务端目录里能找到 `serverconfig.xml`。

启动命令方面，Windows 双击 `startserver.bat` 即可（脚本里带的是 `-configfile=serverconfig.xml -logfile output_log.txt` 这类参数）；Linux 用 `./startserver.sh`。想让服务端在没有图形界面的服务器上跑，可以在启动参数里加上 `-nographics -batchmode -dedicated`，这是社区和 Docker 镜像里通行的做法。

Docker 用户有现成方案，比如 `didstopia/7dtd-server` 和会自动更新的 `xmb233/7dtd-server`，后者基于 Ubuntu 24.04，容器每次启动自动跑一遍 SteamCMD 更新，配置和存档挂载在宿主机的 `./data` 目录下，端口映射 26900/tcp、26900-26903/udp，再加上 8080/8081 的网页面板端口。

## serverconfig.xml 里真正要改的那几项

配置文件有两百多个参数，实际需要动的没几个：

| 参数 | 建议值 | 作用 |
| --- | --- | --- |
| `ServerName` | 自定义 | 服务器列表里显示的名字 |
| `ServerPassword` | 设一个 | 不设的话陌生玩家能直接进来 |
| `ServerPort` | `26900` | 主游戏端口，改了防火墙和客户端连接都要跟着改 |
| `ServerMaxPlayerCount` | 按内存定 | 别超过机器实际能扛的人数 |
| `GameWorld` | `Navezgane` 或 `RWG` | 固定地图还是随机生成 |
| `GameDifficulty` | 0–5 | 数值越大越难 |
| `EACEnabled` | 看 mod 需求 | 装特定 mod 时需要关掉反作弊 |
| `ServerMaxWorldTransferSpeedKiBs` | 512–1300 | 玩家下载世界的速度上限，带宽充裕可以拉到 1300 |
| `ControlPanelEnabled` | `true` | 开启网页控制面板 |
| `TelnetEnabled` | 一般设 `false` | 远程管理用，不用就别开 |

改完记得重启服务端才生效。另外把 `ControlPanelPassword` 和 `TelnetPassword` 从默认值改掉，这两个端口暴露在公网是很常见的被扫目标。

## 端口和防火墙：连不上的九成原因在这

七日杀需要的端口不是只有一个：

- **TCP 26900** — 主游戏端口
- **UDP 26900、26901、26902、26903** — 游戏与查询
- **TCP 8080–8082** — 网页控制面板和 telnet（按需开放，不建议对公网全开）

云服务器上的操作分两步：一是在控制台的防火墙/安全组里放行这些端口，源 IP 填 `0.0.0.0/0` 表示允许所有人；二是在系统内部也要放行，Linux 用 `sudo ufw allow 26900/tcp`、`sudo ufw allow 26900:26903/udp`，Windows 则在防火墙入站规则里给 `7DaysToDieServer.exe` 放行。

玩家那边连接方式：进入游戏 → 加入游戏 → 连接至 IP → 填服务器公网 IP 和端口。

## 固定计费还是动态计费

这是雨云的一个特殊机制，值得单独说。游戏云支持两种计费：

**固定计费**就是传统的按月租金，跑满一个月价格不变。

**动态计费**的基础月租低很多，但 CPU 使用率超过 20% 的部分会按"电量"日结扣费。官方论坛给的价格表里，电量单价从 E5 2666v3 / EPYC 7702 的 0.0005 元/电量，到 7950X、13900K、14900K 的 0.001 元/电量不等，5900X 是 0.0008 元，Gold 6146 和 Platinum 8275cl 是 0.0006 元。

翻译成人话：**七日杀服务端只要有人在线，CPU 就很难压到 20% 以下**，血月那几天更是直接拉满。官方论坛里有人拿自己的生存服做过统计，3 人在线时半天就能烧掉上千电量。所以那种"每天只玩两小时"的碎片化玩法适合动态计费，而想长期稳定开服的腐竹，固定计费更省钱。

优惠方面，官网游戏云页面明确标注新用户可领首月 5 折券；雨云论坛的促销帖里提到年付默认 7 折，配合积分商城的 8 折新购券可以叠到 5.6 折左右。积分商城的券是限量的，每晚 8 点补货。另外官方的规则是 7 天内可无理由退款（每个账号限 3 次），云服务器和游戏云产品支持 1 元试用一天（每款限 1 次），下单前确定不了配置的话，先花一块钱试一天比猜要靠谱。

## 几个常被问到的问题

**2 核 4G 能开七日杀吗？**
原版、地图 8K、两三个人玩，能开。但血月来的时候内存会非常紧张，一旦崩服存档就有风险。预算允许的话直接 4 核 8G 起，省得后面迁移服务器——搬存档比多花几十块麻烦得多。

**一定要装 mod 吗？**
不一定，但装了 mod 内存和 CPU 都要重新算。大型整合包建议按 12GB 内存起步配机器，官方文档里 Darkness Falls 就是这么建议的。

**Linux 还是 Windows？**
Windows 部署更快，双击就能跑；Linux 资源占用更低、稳定性更好，但要处理 32 位依赖和 systemd 托管。如果你不熟悉命令行，选 Windows 不丢人。

**服务器卡顿一定是配置问题吗？**
不一定。先看是不是视距设太高、是不是玩家分散在地图两端同时加载区块、是不是僵尸数量上限开得太大。这些都是配置文件里能改的，改完再考虑加配置。

**服务端版本怎么更新？**
重新跑一遍 `app_update 294420 validate` 就行。更新前把存档目录备份出去，七日杀的实验版更新有可能升级存档结构，导致回不去旧版本。

选服务器这件事，说到底就是算清楚三件事：几个人玩、装不装 mod、要不要长期开。算完对着上面的价格表挑一档，剩下的就是敲命令的活了。
